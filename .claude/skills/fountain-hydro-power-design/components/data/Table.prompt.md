The reporting workhorse: all-caps tracked headers on grey, hairline row rules, tabular figures in right-aligned columns.

```jsx
<Table columns={[{key:"unidad",header:"Unidad"},{key:"mw",header:"MW",align:"right"}]} rows={rows} dense />
```

Use `render` to place a `StatusPill` or `Badge` in a cell. On a 1920×1080 slide pass `scale="slide"` — the default 14px body text is far below the 24px slide minimum.
