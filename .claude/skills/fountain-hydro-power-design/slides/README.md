# Slide templates

Seven 1280×720 slide types built on the geometry read from `Fountain Dark Template.potx`
(88px side margins, title block at 38px, body at 192px, footer band at 668px carrying the
secondary logo flush right).

| File | Use |
|---|---|
| TitleSlide.html | Deck opener — full teal field, negative lockup |
| SectionSlide.html | Chapter break — #212121 |
| ContentSlide.html | Standard body slide on the chevron texture |
| KpiSlide.html | Four operational figures |
| ComparisonSlide.html | Planned vs. executed, two panels |
| TableSlide.html | Work-order detail |
| QuoteSlide.html | Garamond display line over teal-800 |
| ClosingSlide.html | Thanks / contact |

Rhythm for a real deck: title → section → 2–4 content/KPI/table slides → section → … →
quote (at most once) → closing. Never two dark slides in a row, and never more than two
background treatments in one deck.

**Caveat:** `FHPC Template.pptx` and `FHPC Update June 15, 2022 Diseño.pptx` exceeded the
import size limit and could not be opened, so these are built from the `.potx` master
geometry, the palette deck and the logo package — not from FHPC's own finished slides.
Sample content is illustrative placeholder copy, not real plant data.
